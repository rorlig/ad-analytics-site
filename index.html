Technical Details
Google Ads API Usage
Transparency on how we use the Google Ads API in our internal analytics platform.

Data We Access

Campaign, ad group, and ad-level performance metrics including impressions, clicks, cost, conversions, and conversion values via the Google Ads Reporting API (GAQL).

How We Use It

Data is ingested daily into a private database for automated reporting, cross-platform performance comparison, and internal business analytics dashboards.

Access Pattern

Read-only API access. We use the GoogleAdsService.SearchStream method to retrieve reporting data. No campaign modifications, bid changes, or write operations are performed.

Data Storage

All data is stored in encrypted PostgreSQL databases hosted on secured cloud infrastructure. Data is retained for reporting purposes and never sold or shared.

User Authorization

We use OAuth 2.0 for authorization. Users explicitly grant access to their Google Ads accounts. Access can be revoked at any time.

Rate Limiting & Compliance

We respect all API rate limits and quotas. Our application follows Google Ads API Terms of Service and Required Minimum Functionality policies.

Data & Privacy
Your data stays yours
We take data privacy seriously. Here's our commitment.

No Personal Data Collection

We do not collect, store, or process personal user data. Our platform works exclusively with aggregated advertising performance metrics.

No Third-Party Sharing

Advertising data accessed via platform APIs is used exclusively for internal business reporting and is never shared with, sold to, or disclosed to third parties.

Secure Infrastructure

All data is encrypted in transit and at rest. Access is restricted to authorized personnel only. We follow industry-standard security practices.
